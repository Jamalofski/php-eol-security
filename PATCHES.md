# Patches

Security fixes included in each patch level, on top of the last official release
of the branch. Each level includes everything from the previous ones, and names the
exact commit built; [versions.json](versions.json) pins the current level of each branch.

Patch level 1 carries the fix the PHP team published for each branch (status
**upstream**). From patch level 2, the fixes come from
[Remi Collet's backports](https://github.com/remicollet/php-src-security) of the official
php-src fixes, as listed in the NEWS of each branch. The Verification column gives the
result of [`verify_backports.py`](.github/scripts/verify_backports.py) for their commits:
**identical** to the official commit; **identical code** (only NEWS or tests differ);
**same changes, context differs** (the older code around the change differs);
**adapted** (reviewed; the review and the differences are in `verification/<branch>.md`).

### PHP 8.0.30 Patch Level 2 (8.0.30-pl2)

Source: [remicollet/php-src-security@975d905](https://github.com/remicollet/php-src-security/commit/975d905a1681c0708aa88b26b1a7985fcfa517c2)
(branch `PHP-8.0-security-backports`): 53 security fixes published by php-src since 8.0.30.
Verification: [verification/8.0.md](verification/8.0.md), 90 commits: 22 adapted, 38 identical, 15 identical code, NEWS/tests differ, 1 no official commit, 10 no official commit, NEWS/tests only, 4 same changes, context differs.

Remarks from the review (minor; none of them is a security issue):

- GHSA-m8rr-4c36-8gq4: the `-d` value check of the CLI, CGI, FPM and phpdbg SAPIs keeps an uncast `isalnum()` (command-line input only); fix proposed in [remicollet/php-src-security#34](https://github.com/remicollet/php-src-security/pull/34). A few 8.0-only `tolower()` calls, which the official fix does not touch, also stay uncast.
- GHSA-hrwm-9436-5mv3: when escaping fails, `php_pgsql_convert()` does not release the escaped string (a small request-scoped leak). Fix proposed in [remicollet/php-src-security#34](https://github.com/remicollet/php-src-security/pull/34).
- GHSA-3237-qqm7-mfv7: the backport brings `php_read_stream_all_chunks()` from 8.1, which changes how `getimagesize()` reads filtered streams.
- GHSA-fpwc-w8rq-cr92 builds on the GH-11274 change, which makes 307/308 redirects keep the method and body, as 8.1 does.

- GHSA-v8xr-gpvj-cx9g: the backport also brings the 8.0 transfer-encoding cleanup of bug #80256.
